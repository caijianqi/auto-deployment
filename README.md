# Auto-Deployment 自动化部署与监控平台

一个轻量级、零配置的自动化部署与监控平台，专为 SpringBoot (JAR) 和 Vue 3 静态应用量身定制。通过简洁的 Web 界面，实现应用的全生命周期管理。

## 🌟 核心特性

- **多模式应用支持**：原生支持 SpringBoot JAR 包管理与 Vue 静态资源部署。
- **智能进程发现**：支持通过文件路径自动发现并关联系统中已运行的 Java 进程，即插即用。
- **资源池管理**：统一管理部署路径、配置文件（YML）路径以及多个版本的 JDK 环境。
- **在线运维工具**：
  - **在线 YAML 编辑**：直接在浏览器中修改服务器配置文件，自动同步磁盘。
  - **实时日志监控**：基于 WebSocket 的实时日志流预览，支持多种编码格式。
  - **全方位备份**：部署时自动触发版本备份，支持一键秒级回滚。
- **全能文件管理**：支持跨平台（Windows/Linux）浏览服务器目录，内置多语言自动高亮预览器。
- **环境隔离**：支持自定义 JDK 路径，不同应用可使用不同的 Java 运行环境。
- **安全保障**：集成 Sa-Token 轻量级权限框架，支持会话拦截与初始化强制引导。

## 🛠 技术栈

### 后端
- **核心框架**：Spring Boot 3.2.4
- **数据库**：SQLite (内嵌式，无需安装)
- **持久层**：MyBatis-Plus 3.5.5
- **权限安全**：Sa-Token 1.37.0
- **工具类**：Hutool 5.8.26
- **JDK 要求**：JDK 17+

### 前端
- **框架**：Vue 3 (Composition API)
- **构建工具**：Vite 5
- **UI 组件库**：Element Plus
- **样式**：Tailwind CSS (部分原子化样式支持)
- **状态管理**：Pinia
